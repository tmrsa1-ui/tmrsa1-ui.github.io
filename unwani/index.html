عنواني Unwani

تحليل محلي للعناوين الخليجية — بلا تسجيل

ألصق عنوانًا مكتوبًا بأي صيغة.

يعيد النظام المكونات المحتملة مع درجة الثقة والأجزاء غير المفهومة. التحليل يتم في متصفحك. لا يُرسل النص إلى خادم، ولا يُعدّ هذا تحققًا رسميًا.

عنواني محلّل نصّي. ليس بديلًا عن العنوان الوطني أو مكاني أو عنواني أبوظبي أو أنواني قطر. لا نختلق مدينة أو حيًا أو إحداثيات، ولا نضع شارة «موثّق رسميًا» على نتيجة محلية.

حلل عنوانًا

الصق النص كما هو. الأرقام العربية الهندية تُحوَّل للمطابقة مع حفظ الأصل.

قارن عنوانين

المقارنة تُظهر الحقول المتطابقة والمتضاربة والناقصة، لا رقمًا واحدًا فقط.

نسّق عنوان شحن

التنسيق يعيد ترتيب ما استُخرج فقط. لا يُكمل الحقول الناقصة.

افحص عنوانًا مختصرًا

الصيغة المنشورة: أربعة أحرف لاتينية وأربعة أرقام مثل RAGI2929. مطابقة الشكل ليست تحققًا رسميًا.

دليل أنظمة العنونة الخليجية

السعودية — العنوان الوطني (SPL)

رقم المبنى (4) + الشارع + الحي + المدينة + الرمز البريدي (5) + الرقم الإضافي (4). العنوان المختصر: 4 أحرف + 4 أرقام.

الإمارات

دبي: رقم مكاني من 10 أرقام (بلدية دبي). أبوظبي: نظام أونواني Onwani (مبنى، شارع، مدينة، منطقة، رمز بريدي). النظامان مختلفان.

قطر — أنواني

مبنى + رقم شارع + رقم منطقة. المنطقة ليست حيًا وليست مدينة.

البحرين / الكويت / عُمان

غير مدعوم بعد. تُكتشف الدولة فقط ويُرجع الحالة UNSUPPORTED_ADDRESS_SYSTEM. لا تحليل إنتاجي للحقول، ولا تحقق رسمي.

الخصوصية

  • لا تسجيل.
  • التحليل يتم في المتصفح.
  • لا تُرسل العناوين إلى خادم أو نموذج ذكاء اصطناعي.
  • لا تُحفظ العناوين افتراضيًا.
  • لا تحليلات على محتوى العنوان.
  • احذف بيانات الموقع من المتصفح متى شئت.

المنهجية

المسار الأساسي حتمي: تطبيع محافظ → اكتشاف نظام العنونة بعدة إشارات → استخراج بمحدِّدات وروابط نصية → تحقق بنيوي → ثقة مفسَّرة.

كل قيمة مستخرجة تحمل span إلى النص الأصلي. لا يُملأ حقل مفقود من الجريدة الجغرافية إذا لم يرد في النص.

SYNTAX_VALID تعني أن الشكل يطابق قواعد النظام المتوقع، وليست تحققًا رسميًا.

المصادر

  • SPL — National Address: splonline.com.sa
  • National Address API portal: api.address.gov.sa (غير مستدعى في هذا الإصدار)
  • Makani open data — Dubai Municipality: dm.gov.ae
  • Onwani — DMT Abu Dhabi: pages.dmt.gov.ae/en/onwani
  • Qatar Post Anwani: qatarpost.qa

عند استخدام بيانات مكاني لاحقًا يجب ذكر المصدر: بلدية دبي. لا يجوز بيع بيانات مكاني الخام.

API للمطورين
